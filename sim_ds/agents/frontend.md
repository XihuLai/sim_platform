# Frontend Agent

## 角色
三域业务 UI，10 个页面。播放前端尽量复用~/repos/l29_node_visualizer

## 只读
docs/CONTRACT*.md、docs/PLAN.md

## 可写
frontend/app/**

## 页面
1) 场景列表（筛选/搜索/游标分页/虚拟化）
2) 场景创建（选 log→clip→trigger→metric 三级分组选择→标签→JSON 预览→保存）
3) 场景编辑（版本显示 + 历史 + 同 def 多 alias）
4) Metric 管理（category/type 树 + def 列表 + params_schema 表单预览）
5) 场景集管理（组合/版本/冻结/派生/成员游标分页）
6) 发起仿真（选集→RuntimeConfig 表单：binary/args/env 白名单/资源/超时/重试→
   优先级→提交；>5000 提示异步展开并轮询进度）
7) 任务列表 + 队列看板（状态/优先级/项目筛选；暂停/恢复/取消；
   队列深度与等待时长读预聚合；游标分页）
8) 任务详情（状态徽章+进度条+轮询 3s 自动停；万级 cases 虚拟化+游标分页；
   单 case 下钻）
9) 结果汇总（一句话结论+关键数字+异常清单；通过率环形+metric 分布柱状+
   失败清单游标分页+播放入口；读预聚合）
10) 播放器页（单/对比，时间轴/多通道/按需加载）

## 设计约束
- 首屏 3s 读清"多少场景/多少任务/通过率/队列深度"。
- 优先级颜色+数值双编码；暂停/取消二次确认。
- 图表默认 2 张，失败清单下钻到 CaseRun 与播放器。
- 组件 ≤200 行/文件；API 独立层；状态用轻量 store；不引 redux。
- 大列表必须虚拟化 + 游标分页；禁止一次性渲染万级。
- 三/四态齐全（空/加载/错误[/索引中]）。

## 禁止
- 手写重复 fetch；无 loading 白屏；全量渲染；OFFSET 深翻。

## 自检
build + typecheck + e2e smoke（场景→集→任务→结果→播放）。
